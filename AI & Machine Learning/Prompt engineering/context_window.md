# Context Window

Context window — це обсяг інформації, який AI-модель може бачити та враховувати одночасно під час генерації відповіді.

- Вимірюється в tokens.
- У context входять:
  - повідомлення користувача,
  - відповіді AI,
  - код,
  - документи,
  - системні інструкції.
- Якщо ліміт перевищено — старий контекст “випадає”.
- Великий context window дозволяє:
  - аналізувати великі проєкти,
  - підтримувати довгі розмови,
  - працювати з великими codebase.

## Важливо
Більший context ≠ краще розуміння.
Для великих систем часто використовують:
- RAG,
- embeddings,
- vector databases.
