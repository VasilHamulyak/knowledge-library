# Zero-Shot Prompting

## Що таке Zero-Shot Prompting?

Zero-Shot Prompting — це техніка взаємодії з AI-моделлю, коли завдання описується без надання прикладів.

Модель виконує задачу, спираючись лише на знання, отримані під час навчання.

---

## Основна ідея

Користувач надає лише інструкцію:

"Класифікуй текст як позитивний або негативний."

Модель одразу виконує задачу без демонстрацій чи прикладів.

---

## Приклад

### Prompt

Визнач тональність тексту:

"Цей продукт перевершив усі мої очікування."

### Відповідь

Позитивна тональність

---

## Як працює

1. Користувач формулює завдання.
2. Модель аналізує інструкцію.
3. Використовує власні знання.
4. Генерує результат.

---

## Де використовується

### Класифікація
- Sentiment Analysis
- Spam Detection
- Category Classification

### Генерація тексту
- Статті
- Email
- LinkedIn Posts
- Опис продуктів

### Аналіз інформації
- Резюме документів
- Виділення ключових тез
- Витягування даних

### Генерація коду
- Функції
- API Endpoints
- Unit Tests

---

## Переваги

- Простота використання.
- Швидке створення prompt-ів.
- Не потрібно готувати приклади.
- Підходить для більшості стандартних задач.

---

## Недоліки

- Нижча точність для складних задач.
- Результат залежить від якості інструкції.
- Може неправильно інтерпретувати вимоги.
- Гірше працює зі специфічними доменними задачами.

---

## Best Practices

### Будьте конкретними

Погано:
"Проаналізуй текст."

Добре:
"Визнач основні ризики проєкту та поверни результат у Markdown."

### Вказуйте формат

Наприклад:
- JSON
- Markdown
- Таблиця

### Вказуйте роль

"Ти Senior Software Architect."

### Надавайте контекст

Чим більше релевантного контексту, тим кращий результат.

---

## Zero-Shot vs Few-Shot

### Zero-Shot
- Без прикладів.
- Простий prompt.
- Швидкий запуск.

### Few-Shot
- Є приклади.
- Вища точність.
- Кращий контроль результату.

---

## Коли використовувати

Використовуйте Zero-Shot, якщо:
- задача проста;
- приклади відсутні;
- потрібен швидкий результат;
- модель добре знайома з предметною областю.

---

## Головна думка

Zero-Shot Prompting дозволяє AI виконувати задачі лише на основі інструкції без попередніх прикладів, що робить його найпростішою та найпоширенішою технікою prompt engineering.
