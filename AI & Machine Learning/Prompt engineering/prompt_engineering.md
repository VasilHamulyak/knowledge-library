# Prompt Engineering

## Що таке Prompt Engineering?

Prompt Engineering — це процес проєктування, тестування та вдосконалення запитів (prompts) для AI-моделей з метою отримання точних, корисних і передбачуваних результатів.

---

## Основна мета

- Отримати якісніші відповіді від AI.
- Зменшити неоднозначність.
- Контролювати формат і стиль результату.
- Підвищити повторюваність результатів.

---

## Ключові принципи

### 1. Чіткість
- Формулюйте завдання максимально конкретно.
- Уникайте двозначностей.

### 2. Контекст
- Надавайте необхідну інформацію для виконання завдання.
- Вказуйте роль, аудиторію та обмеження.

### 3. Структура
- Розбивайте складні завдання на кроки.
- Використовуйте списки та секції.

### 4. Приклади
- Показуйте бажаний формат відповіді.
- Використовуйте few-shot prompting.

### 5. Ітеративність
- Аналізуйте результат.
- Покращуйте prompt поступово.

---

## Популярні техніки

### Zero-shot Prompting
Модель виконує завдання без прикладів.

### Few-shot Prompting
Модель отримує декілька прикладів перед виконанням.

### Chain of Thought
Стимулювання покрокового міркування.

### Role Prompting
Призначення моделі певної ролі.
Наприклад: «Ти Senior Software Architect».

### Structured Output
Вимога повернути результат у форматі:
- Markdown
- JSON
- XML
- Таблиця

---

## Хороший Prompt зазвичай містить

1. Роль
2. Контекст
3. Завдання
4. Обмеження
5. Формат відповіді
6. Критерії якості

### Приклад

Ти Senior Backend Engineer.

Контекст:
Ми розробляємо FastAPI-проєкт.

Завдання:
Створи структуру проєкту.

Обмеження:
- Clean Architecture
- Python 3.13
- PostgreSQL

Формат:
Покажи дерево директорій у Markdown.

---

## Типові помилки

- Занадто загальні інструкції.
- Відсутність контексту.
- Відсутність вимог до формату.
- Надто багато різних завдань в одному prompt.
- Нечіткі критерії успіху.

---

## Практичне правило

Якість відповіді AI часто прямо залежить від якості prompt.
Чим більше релевантного контексту та чітких вимог, тим кращий результат.
