# Zero-Shot Prompting Techniques

## Що таке Zero-Shot Prompting Techniques?

Zero-Shot Prompting Techniques — це набір технік створення prompt-ів, які дозволяють AI виконувати завдання без надання прикладів.

Модель отримує лише інструкцію та використовує знання, отримані під час навчання.

---

## Основна ідея

Замість:

Input + Examples + Task

використовується:

Input + Task

Приклад:

"Підсумуй цей документ у трьох реченнях."

Без демонстрації очікуваного результату.

---

## Основні техніки

### 1. Direct Instruction

Пряме формулювання завдання.

Приклад:

"Напиши опис продукту для інтернет-магазину."

---

### 2. Role Prompting

Призначення ролі моделі.

Приклад:

"Ти Senior Software Architect. Проаналізуй архітектуру системи."

---

### 3. Output Formatting

Визначення формату відповіді.

Приклад:

- Поверни результат у JSON.
- Створи таблицю в Markdown.

---

### 4. Constraint Prompting

Додавання обмежень.

Приклад:

- Не більше 200 слів.
- Використовуй українську мову.
- Не використовуй списки.

---

### 5. Context-Based Prompting

Надання контексту без прикладів.

Приклад:

"Ми будуємо FastAPI платформу для маркетплейсу. Запропонуй архітектуру."

---

### 6. Step-by-Step Prompting

Прохання виконати задачу покроково.

Приклад:

"Поясни рішення крок за кроком."

---

### 7. Task Decomposition

Розбиття складної задачі на підзадачі.

Приклад:

1. Проаналізуй вимоги.
2. Запропонуй архітектуру.
3. Опиши API.
4. Запропонуй тестування.

---

## Best Practices

### Будьте конкретними

Погано:

"Напиши статтю."

Добре:

"Напиши технічну статтю про FastAPI для Senior Backend Engineers."

### Вказуйте аудиторію

- Developers
- Product Managers
- CTO
- Investors

### Вказуйте формат

- JSON
- Markdown
- XML
- Таблиця

### Вказуйте обмеження

- Максимальна довжина
- Мова відповіді
- Стиль написання

---

## Переваги

- Простота використання.
- Швидке створення prompt-ів.
- Не потрібні приклади.
- Підходить для багатьох задач.

---

## Недоліки

- Нижча точність для складних задач.
- Менший контроль над результатом.
- Часто потребує уточнення prompt-а.

---

## Zero-Shot vs Few-Shot

### Zero-Shot

- Без прикладів.
- Швидкий старт.
- Простий prompt.

### Few-Shot

- Є приклади.
- Вища точність.
- Кращий контроль результату.

---

## Головна думка

Zero-Shot Prompting Techniques допомагають отримувати якісні результати без прикладів, використовуючи правильне формулювання інструкцій, контексту, ролей, обмежень і формату відповіді.
