# LLM (Large Language Model)

## Що таке LLM?

LLM (Large Language Model) — це велика мовна модель штучного інтелекту, навчена на величезних обсягах текстових даних для розуміння та генерації людської мови.

LLM може:
- відповідати на запитання;
- генерувати тексти;
- писати код;
- аналізувати інформацію;
- перекладати;
- виконувати логічні міркування.

---

## Основна ідея

Користувач надсилає prompt.

LLM:

1. Аналізує текст.
2. Визначає контекст.
3. Передбачає найбільш імовірне продовження.
4. Генерує відповідь.

---

## Як працює LLM

Input (Prompt) -> Tokenization -> Transformer Model -> Probability Prediction ->  Generated Response

---

## Основні компоненти

### Tokens

Текст розбивається на невеликі частини — токени.

Наприклад:

"Hello world"

може бути:

["Hello", " world"]

---

### Transformer

Основна архітектура сучасних LLM.

Transformer дозволяє моделі:

- враховувати контекст;
- знаходити зв'язки між словами;
- працювати з великими текстами.

---

### Attention Mechanism

Механізм уваги визначає, які частини тексту є найбільш важливими.

---

### Parameters

Параметри — це внутрішні ваги моделі.

Сучасні LLM можуть містити:

- мільярди параметрів;
- десятки або сотні мільярдів параметрів.

---

## Навчання LLM

### Pretraining

Модель навчається на великих масивах текстів.

Задача:

Передбачити наступний токен.

---

### Fine-Tuning

Додаткове навчання для конкретних задач.

Наприклад:

- медицина;
- юриспруденція;
- програмування.

---

### Alignment

Налаштування поведінки моделі для взаємодії з людьми.

## Недоліки

- Можуть помилятися (hallucinations).
- Не мають справжнього розуміння світу.
- Вимагають значних ресурсів.
- Обмежені знаннями з тренувальних даних.

---

## LLM vs AI Agent

### LLM

- Генерує відповіді.
- Не має власної цілі.
- Не виконує дії самостійно.

### AI Agent

- Використовує LLM як мозок.
- Планує дії.
- Використовує інструменти.
- Досягає поставлених цілей.

---

## Взаємозв'язок

User -> AI Agent -> LLM -> Tools -> Result

LLM є центральним компонентом більшості сучасних AI Agent систем.

---

## Головна думка

LLM (Large Language Model) — це фундаментальна технологія сучасного генеративного AI, яка дозволяє машинам розуміти та генерувати людську мову, а також слугує основою для чат-ботів, AI-агентів та інтелектуальних автоматизованих систем.
